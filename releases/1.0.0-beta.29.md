# 1.0.0-beta.29 — Under the hood: layouts leave the shell

The fifth restructuring release, and the first to open up the largest file in the app: the Desk
shell, which holds the sidebar, the panes, the tabs and everything that ties them together. One
part moved out into its own file this time, and only one: saved layouts and the `Ctrl+1`–`6`
slots. Later releases take the next parts, one at a time. Nothing should look different.

## What's new

- Nothing visible.

## What to test

Everything about layouts:

- Press `Ctrl+1` to `Ctrl+4` and check each built-in layout (Write, Plan, Research, Review) opens.
- Arrange some tabs and a split, then **Layout → Save layout…**, give it a name and a shortcut
  slot. Press that slot's key from a different arrangement and check it comes back.
- Change the arrangement and check the layout shows as modified; choose **Update** and check
  the dot clears.
- **Manage layouts…**: rename one, move it to another slot, delete one, **Restore the four
  defaults**.
- Open a layout from the command palette.
- In Settings → Desk, set **On launch, open** to a layout, quit and reopen.
- `Ctrl+Shift+T` still jumps to Today.

## Known issues

- None new. The open items from beta.19 still stand.
