# 1.0.0-beta.36 — Your date format, wherever dates are written in numbers

## What's new

- **The date format you chose in Settings → Planner now applies everywhere a date is written in
  numbers.** Before, only the notes tree used it. Five other places showed a numeric date in
  whatever form the system picked: the tooltips on rows in the activity log and in a project's
  history, a template's "Updated …", "last synced …" in Settings → About, and "updated …" on
  the account card. They now use mm/dd, dd/mm or ISO as you set it, and change the moment you
  change the setting.
- **Dates written with words are unchanged.** "Oct 5", "Thursday, October 1" and project ranges
  like "Mar 1 – Sep 20" follow your system language, as before. When we looked, almost every
  date in Hollow turned out to be written this way, so the visible change is small.

## What to test

- In Settings → Planner, switch Date format between the three choices. Then check the tooltip on
  an activity-log row (hover it), "last synced" in Settings → About, and a template's "Updated"
  tooltip each show the date in that format.
- Check the journal entries in the notes tree still follow the setting.

## Known issues

- Date pickers (the small calendar boxes when you set a due date) are drawn by the system and
  follow the system language, not this setting.
- The time shown next to those dates follows the system's 12- or 24-hour style, not Hollow's own
  time-format setting.
- The command palette reads a typed date such as `5/10` as month first, whichever format you chose.
- The open items from beta.19 still stand.
