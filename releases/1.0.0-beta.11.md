# 1.0.0-beta.11 — Project follow-ups

Small fixes to beta.10's project tracking: task priority can be set again, Undo after a drag puts
things back properly, and the Calendar and project headers fit half a split. The phone app is
unchanged.

## What's new

- **Priority is back.** A task's detail has a **Priority** field — None, P1, P2 or P3 — and P1–P3
  show on its row. Beta.10 removed the Board, which was the only place to set it. You can also type
  **!1**, **!2** or **!3** when you add a task.
- **Undo after dragging a finished task** out of Done now completes it again properly. Before, it
  came back without its completion date and dropped out of the List's Done group.
- **Undo after dragging a task between milestones** moves it back without undoing anything you
  changed on the project in the meantime.
- **Opening a project from the Timeline** switches a project page that's already open to its tasks
  grouped by milestone, instead of leaving it as it was.
- **"Show in Calendar to the side"** from a day's tasks always shows every project, even if that
  Calendar tab was filtered to one earlier.
- **Narrow panes.** In half of a split, the Calendar's **Habits** and **Hours** switches fold into
  one **View ▾** menu, and a project's progress line moves under its name instead of being cut
  off.
- **Notes tree wording.** A project's folder menu says **Open project**, **Rename project** and
  **Put on ice** (it said "section"). Put on ice asks about due dates the same way the project's
  status menu does.

## What to test

- Set a task's Priority to P1, P2, P3 and None from its detail; add one with `!2`.
- In the List grouped by Status, drag a done task into Doing, then **Undo**. It should be back in
  Done with its tick.
- On a project's Tasks tab grouped by Milestone, drag a task to another milestone, rename a
  milestone, then **Undo** the drag. The task goes back; the rename stays.
- Split the window, put Calendar in one half and a project in the other, and check both headers.
- Right-click a project's folder in Notes → **Put on ice**, with and without dated tasks.

## Known issues

- Two devices editing the same project's milestones or status while one of them is offline can
  lose one of the edits. Under investigation — see the project follow-ups plan.
- The phone's project screens are unchanged.
