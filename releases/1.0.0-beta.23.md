# 1.0.0-beta.23 — Under the hood: one way to do each thing

The fourth housekeeping release after the 1 October code review. The earlier three removed and
documented; this one unifies. Where the code had several copies of the same idea (what "today"
is, how a status is spelled, how an error reaches you), there is now one. A few of those copies
disagreed with each other, so some things you can see have changed. They are listed first.

## What's new

- **Status names agree everywhere.** The task editor's small "Task · …" line used to say *open*,
  *in progress* and *done*; the List's group headers said *Todo*. Both now use the same six
  words as the Status menu: **Backlog, To do, Doing, Blocked, Done, Archived**.
- **The phone's Tasks list groups like the desktop List**: Overdue · Today · Next 7 days · Later ·
  Unscheduled · Paused projects · Done. It used to have its own Late / Upcoming / Completed
  buckets. Done stays hidden until you show it, as before.
- **A failed save or load now tells you.** Some background saves and a few loads used to fail
  silently, so a list could look empty or a change could quietly not stick. Those now show a
  short message and keep what was on screen.
- **Error messages are shorter.** When something goes wrong in a save, the message no longer
  starts with the technical "Error invoking remote method…" prefix.
- **Two date fixes.** The line that Hollow appends to a note when you complete a task now carries
  the local date (it used the UTC date, so a late-evening completion could be stamped with
  tomorrow). Exported task files show the due and do dates on the correct local day for the same
  reason.
- Dates in the Desk and project screens follow your system locale instead of always US English.
  On a US-English machine nothing changes.
- **Two bugs found while making failures visible.** A project could lose the link to its index
  page if a single read failed in the background; and a template tab could close itself as if
  the template had been deleted when one load failed. Both now report the error and keep their
  state.
- **Links open the same way, more carefully.** Anything that tries to open a new window inside
  Hollow is refused and, if it is a normal web or mail link, handed to your browser or mail app as
  before. The app's screen area also now runs in Chromium's sandbox, which is the stricter
  default Electron recommends. You should notice nothing; if a button or link stops working,
  that is the thing to report.

## What changed underneath

- One date module, one id generator, one status-label table, one error shape across the
  desktop's internal boundary, and one task hook shared by the desktop List and the phone.
- Habit streaks for the Habits grid load in a single request instead of one per habit.
- Tests run under a declared time zone with daylight-saving transitions, and three tests that
  depended on the wall clock no longer do.

## What to test

- Open a task in the editor and check the "Task · …" line and the Status menu use the same words.
- Open Planner → List grouped by status and check the headers read Backlog / To do / Doing /
  Blocked / Done.
- On the phone layout (or a narrow window): open Tasks and check the group names above.
- Complete a task with "append to note" set and check the note line shows today's date.
- Export a task with a due date (Settings → Account & data → Export) and check the `due:` line.
- Go offline or break nothing on purpose; just use the app for a while and report any new toast
  that appears without you having done anything wrong.

## Known issues

- None new. The open items from beta.19 still stand.
