# 1.0.0-beta.41 — Under the hood: a lighter notes tree

The notes tree in the sidebar (folders, notes, the Journal, templates) was one very large file.
It is now a set of small ones, and it does less work as you use it. It should look and behave
exactly as before.

## What's new

- **The notes tree redraws less.** Selecting a note used to redraw every row in the tree; now
  only the two rows that changed are redrawn. Dragging over the tree and collapsing a section
  redraw none. With many notes this should feel a little snappier.
- **Templates are laid out once.** With many templates and folders the Templates section did
  repeated work for every folder; it no longer does.
- Dropping something that is not a Hollow note onto the tree is ignored instead of causing an
  error behind the scenes.

## What to test

The sidebar's notes tree, thoroughly:

- Click, `Ctrl`-click and `Shift`-click notes to select one, several and a range. Use the arrow
  keys, `Enter`, `F2` to rename, `Ctrl+X` / `Ctrl+C` / `Ctrl+V`, `Ctrl+A`.
- Drag a note into a folder; drag a folder into another; try dragging a folder into one of its
  own subfolders (it should refuse) and try moving the Journal (it should refuse).
- Expand and collapse folders, the Journal's months and project sections; quit and reopen and
  check they are as you left them.
- Open a note from elsewhere (search, a link) and check the tree reveals it.
- Rename a note and a folder in place. Right-click menus still work on notes, folders,
  templates and a multi-selection.
- The Templates section: folders, templates inside them, templates with no folder.

## Known issues

- Arrow keys skip template folder rows in the tree.
- The open items from beta.19 still stand.
