# 1.0.0-beta.13 — Beta readiness fixes

A pass over the rough edges found while checking the app and this guide before more people try it.
The in-app Help has been checked page by page against the app, and there is a new **Workflows**
page with step-by-step recipes for everyday things (Help → Workflows). The phone app is unchanged.

## What's fixed

- **Quick capture keeps priority.** Typing `!1`, `!2` or `!3` in Quick capture (`N`) now sets the
  task's priority. Before, it removed the `!1` from the title and saved nothing.
- **Templates stamp today's date.** `{{date}}` used the date in UTC, so a note made in the evening
  west of UTC got tomorrow's date.
- **A new template isn't lost** if you close it before naming it: it saves as *Untitled template*.
- **`Ctrl+Shift+B` only opens Report a bug.** In a note it also turned the line into a quote.
- **`@1/5` means next January** when you type it in September, not a date already overdue. In the
  command palette, a date still means this year, so you can jump back to a past day.
- **Signing out works offline.** Before, it could stop with an error if the server couldn't be
  reached.
- **Restore while signed in** now tells you how to do it, instead of asking you to confirm first and
  then refusing in developer language.
- **"Local profile synced to cloud"** no longer appears when the upload failed.
- **Palette: New note in a project** is only offered for projects whose page is written, so the note
  doesn't land in a folder the Notes tree hides.

## What's changed

- **Sign off for today** is on the right-click menu of **Today** in the sidebar, as well as in the
  command palette.
- A task's **More details…** has a **Status** field (Backlog, Todo, Doing, Blocked). Tick the check
  to mark a task done.
- The day's **Schedule** menu (right-click a task in a day's list) offers the seven days from the
  day shown, weekend included, with dates.
- The Calendar's Pool labels a task planned for next week *next week*, not *this week*.
- The red **Sync stalled** pill opens **Settings → About**, where **Copy sync diagnostics** is.
- Shortcut hints show `Ctrl+` on Windows instead of Mac symbols (sidebar, top strip, Help).
- **Settings → Shortcuts** matches the real shortcuts.
- **Settings → Data** explains backups without internal file names.
- The Activity log says when it is only showing the latest 1,000 changes.
- The editor's `@` button is called **Link a note**, which is what it does.
- Removed three settings that did nothing: **Settings → Modules → Quick add bar**, a project's
  **Default task**, and a habit's **Remind** (no reminder was ever sent). Anything you had set is
  kept, in case they come back.

## What to test

- Quick capture: `Pay rent !1 @fri`. It should be P1, due Friday, titled "Pay rent".
- A template with `{{date}}`, used late in the evening.
- In a note, press `Ctrl+Shift+B`. The bug reporter opens and the line doesn't change.
- Right-click **Today** → **Sign off for today**.
- Open a task's **More details…** and change its **Status**.
- Signed in, **Settings → Data → Restore backup**. You should get an explanation, not a
  confirmation.
- Sign out with the network off.

## Known issues

- Two devices editing the same project's milestones or status while one of them is offline can
  lose one of the edits. See the project follow-ups plan.
- The phone's project screens are unchanged, and the phone can't yet start in local mode.
