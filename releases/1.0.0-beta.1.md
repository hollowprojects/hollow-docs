# 1.0.0-beta.1

The first beta was the one that proved sync worked. This one is the repair pass that came out
of actually living in it: a data-corruption bug that had been quietly running since July, the
subtask editor that wouldn't hold what you typed, and a handful of things that only show up
once you sign in on a real build.

## What's new

**Subtasks stay put.** Pressing Enter in a subtask row now creates the next row instead of
deleting the one you just made, on both tasks and habits. Editing a habit's steps no longer
loses uncommitted text when the habit saves and reloads underneath you.

**Start of week actually applies.** Changing it in Settings now updates the Planner calendar,
the habits grid and the week views immediately, instead of only after a restart.

**Calendar: Planned only.** A new view mode that hides the Pool, the per-cell add buttons and
drag-and-drop, showing just what is actually scheduled. The habits toggle keeps working inside
it.

**Right-click spelling suggestions.** Misspellings were underlined but there was no menu to act
on them. Right-click now offers suggestions, "Add to dictionary", and the usual Cut / Copy /
Paste, in the editor and every other text field.

**Notes no longer hang on a spinner after signing in.** The daily note load has a timeout and
an error state with a Try again button, rather than spinning forever if it fails.

## Fixes that touch your data

**JSON columns were corrupting on every sync.** Tags, subtasks, habit recurrence and activity
metadata were being stored in the cloud as quoted text rather than real JSON, so they came back
in a shape the app didn't expect. Depending on where they were read, that showed up as subtasks
that wouldn't load, habit settings that reverted to defaults, or a panel that failed to render.
Uploads now send real JSON, reads tolerate the old shape, and the existing rows have been
repaired in place. Nothing of yours was lost.

**A settings row had grown to 17 MB.** A side effect of the same bug: each save was merging the
corrupted value into itself character by character, multiplying the row every time and shipping
the whole thing to every device on each sync. It's fixed at the source and the row has been
reset — **if you had preferences that lived in your account, set them again.**

**Signing in no longer creates a second "Daily" folder.** On the first sign-in the app asked for
your folders before sync had delivered them, decided Daily was missing and made a new one, which
split the journal across two folders. It now waits for the first sync, and the Journal folder is
resolved properly rather than by matching the name "Daily" — so renaming it is safe, and it can
no longer be deleted by accident.

**Sidebar crashes are contained.** A failure in the notes sidebar or the calendar Pool used to
take the whole window white. Those panels now fail on their own with a Try again button, and log
what actually went wrong.

## What to test

1. **Habits and subtasks.** Add several subtasks with Enter, to a task and a habit. Close and
   reopen. They should all be there.
2. **Your journal.** Check the Daily folder — September 19 and 20 should be in the same one, and
   there should be only one Daily folder.
3. **Start of week.** Change it in Settings and watch the Planner calendar without restarting.
4. **Settings.** Anything you'd set on your account is back to defaults; set it again and confirm
   it sticks after a restart.
5. **Sync.** The pill should settle to synced. Tags and subtasks created on this build should
   survive a restart with their shape intact.

## Known issues

- **Self-update still doesn't work.** The MSI can't carry updates and the NSIS installer aborts
  silently on this machine, so beta 2 will be another manual install.
- **The two-device test hasn't happened yet.** Everything so far is one machine.
- iOS remains parked until the Apple developer account exists.
