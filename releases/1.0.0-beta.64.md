# 1.0.0-beta.64 — Testing sync with real data

Nothing in this release changes what you see. It adds the tools to test sync between devices
using the sample datasets instead of an empty account, and the first run of them found a sync
problem worth knowing about.

## What's new

- For people working on Hollow's code: each sample dataset now has its own dedicated test
  account. A development build signed in to one of them can load that dataset into the account
  from the developer-only **Debug** settings, and sync then uploads it, so a second device has a
  full desk to download and compare. Only a dataset's own test account is accepted: any other
  account, including a real one, is refused.
- For people working on Hollow's code: a script signs a scratch copy of the app in to a test
  account without anyone typing a password.

All of this exists only in development builds.

## What to test

- Nothing new. Use Hollow as you normally do: open today's page, add and complete a task, keep a
  habit, and check sync still settles if you are signed in.

## Known issues

- **Signing in on a second computer can reset your name and settings.** When a computer that
  has never had Hollow on it signs in to an existing account, it can replace the account's display
  name with "User" and reset its synced settings (density, editor and date preferences), and it can
  add a second page for today. Found while testing this release; not fixed yet. Until it is, if
  you sign in on a new computer, check **Settings** afterwards and set them again if needed.
- The open items from beta.19 still stand.
