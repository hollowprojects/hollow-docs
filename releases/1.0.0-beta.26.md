# 1.0.0-beta.26 — Under the hood: the palette, the notes menus and the task list

The second restructuring release. Three more large source files were taken apart: the command
palette, the right-click menus of the notes tree, and the task list. Everything should look and
behave as it did, with one improvement you may feel.

## What's new

- **The task list is lighter while you type.** Typing in the capture bar, dragging a task over a
  group, or opening a menu used to redraw every row in the list. Now only the rows that changed
  are redrawn. On a long list this should feel a little snappier; nothing should look different.
- Two right-click menu items in the notes tree (the template choices and "Put on ice") could
  act on slightly out-of-date information in rare cases. They now always use the current state.

## What to test

- **Command palette** (`Ctrl+K`): search for a note and a task, open one; run a few commands
  (New note, a Settings group, a layout, "File under…"); type a date to jump to a journal day.
- **Notes tree menus**: right-click a note, a folder, a project folder and a multi-selection.
  Try rename, move, favourite, archive, duplicate, export, cut and paste, copy link, delete,
  sort, expand and collapse.
- **Task list** (Planner → List and a project's Tasks tab): add a task from the capture bar and
  from a group's add row; change status by clicking the status chip; set a date from the row's
  date menu; drag a task between groups and use Undo; change the grouping; collapse a group and
  reload to check it stays collapsed; open a task's detail.

## Known issues

- None new. The open items from beta.19 still stand.
