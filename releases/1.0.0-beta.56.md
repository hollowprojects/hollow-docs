# 1.0.0-beta.56 — The notes tree is a real tree for screen readers and the keyboard

## What's new

- **`Tab` stops in the notes tree once.** It lands on the open note, or the row you last used;
  the arrow keys move inside the tree, and `Tab` again leaves it. Before, `Tab` stopped on every
  row.
- **Type a letter** to jump to the next row that starts with it.
- **"+ New template" can be reached with the arrow keys.**
- **After renaming with `F2`, focus returns to the renamed row.**
- **For screen readers:** the tree is announced as a tree. Each row says its level and position
  ("level 2, 3 of 7"); folders, months and headings say expanded or collapsed; section headings
  (Journal, a project, Favorites, Templates, Archive) are rows like any other; selected notes
  are announced as selected, and the open note as current. An open, empty folder reads
  "No notes" with its heading.
- Nothing looks different, and the mouse, drag and drop and the existing keys behave as before.

## What to test

- Press `Tab` until focus enters the notes tree: it should take one press to get in and one to
  get out. Move with the arrow keys; `Right` opens a folder, `Left` closes it.
- Type the first letter of a note's name.
- `F2` to rename, `Enter` to finish: focus is back on the row.
- Click, `Ctrl`-click and `Shift`-click notes; drag a note into a folder; right-click a note.
  All as before.
- Collapse a folder that holds the row you were on, then press `Tab` into the tree again: it
  lands on a visible row.
- With a screen reader, arrow through the tree and listen for level and position.

## Known issues

- You cannot yet extend a selection with `Shift` and the arrow keys; use `Shift`-click.
- The open items from beta.19 still stand.
