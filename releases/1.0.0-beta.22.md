# 1.0.0-beta.22 — Under the hood: the docs tell the truth

The third housekeeping release after the 1 October code review. Nothing in the app changes.
This one is about the project's own documentation: the pages that describe how Hollow is built
had drifted from the code in several places, and nothing stopped that from happening again.
Both are fixed. The user guide inside the app (Help, `F1`) is unchanged.

## What's new

- Nothing visible in the app.

## What changed underneath

- The developer documentation was re-checked against the code and corrected (counts, file
  names, removed features that were still described as present).
- Every plan and review document now carries a status header, and finished ones moved to an
  archive folder, so the live set is short and current.
- New automated checks fail the build when a documented number no longer matches the source,
  when a finished plan is left in the live folder, or when a document is not indexed.

## What to test

- Open Help (`F1`) and check the guide pages and release notes still open and read correctly.
- Otherwise, treat this as beta.21: nothing else should have changed.

## Known issues

- None new. The open items from beta.19 still stand.
