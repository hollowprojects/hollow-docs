# 1.0.0-beta.10 — Projects you can track

Projects are rebuilt around tracking: each project page now shows how far along it is, what's
next and what's late. Milestones can be edited in place, and tasks can be dragged between groups.
The kanban **Board is gone**: a project's tasks are a grouped list, the same one Planner uses. The
Projects view gains **Needs attention** and a **Timeline**. The phone app is unchanged.

Full guide: **Help → Planner** (the Projects section), **Help → Capturing tasks** and
**Help → Keyboard shortcuts**.

## What's new

### A project page

- **One header**: a **Projects /** link back to the list, the name, a **status** menu (Active, On
  ice, Done), a line such as "4 of 10 done · 1 overdue · next Today", a bookmark to pin it, and
  **⋯** with **Edit project…** and **Open tasks in Calendar**.
- **Four tabs: Overview · Tasks · Notes · Activity.** The project remembers the last one you had
  open.
- **Overview** shows the project's **Focus**, the current milestone and its progress, **Next up**
  (with an input to add tasks), recent notes, and a side card with every milestone, the dates and
  the latest activity. A new project shows **Get this project going**: a focus, a milestone, a few
  tasks.
- **Tasks** is Planner's List for this project: group by **Status**, **Milestone** or **Due**.
- **Notes** starts with the **project page**, which now opens as an ordinary note. **Graph** has
  moved here. **+ New note** now uses the project's default note template — it used to ignore it.
- **Activity** replaces History: filter to Tasks, Notes or Project, grouped by day.
- Press **N** on a project page to jump to its task input.

### Milestones

- **Add** a milestone from the project's Overview; it's due in two weeks.
- On **Tasks → Milestone**, each milestone's **⋯** renames it, moves it a week either way, picks a
  new date, or deletes it (its tasks keep their dates).
- Put a task in a milestone from its detail (**Milestone**), by right-clicking it, by pressing
  **M**, by dragging it into the milestone's group, or by typing **^beta3** when you add it.
- Milestones show on the **Calendar** as ◆ in the project's colour, and on the Projects **Timeline**.

### Dragging between groups

- In any task list, drag a task onto another group to change what the group is about: its status,
  milestone, project or due date. **Undo** appears after each move.
- Empty groups appear while you drag, so you can drop into them.

### Adding tasks

- **@date now sets the due date** — in the List, on project pages and in Quick capture — so a task
  lands on that day in the Calendar. Quick capture's **Do date** field still sets the do date.
- **^milestone** puts the new task in a milestone.
- The input shows what it will set as you type: `due Fri · ◆ Beta.3`.

### The Projects view

- **List** and **Timeline**, a name filter, and sorting by Recent, Due or Name.
- Rows show the current milestone, a progress bar, the next due date and an overdue badge.
- **Needs attention** collects active projects with overdue work, three quiet weeks, or a milestone
  due within ten days that is less than half done.
- **+ New project** just asks for a name. **New project…** is also in the command palette.

### Pausing and finishing

- **On ice** asks whether to **pause due dates**. Paused tasks keep their dates but leave Today and
  Overdue, and wait under **Paused projects** in the List.
- **Done** asks what to do with open tasks, and can write a **close-out note**.

### Also

- The Calendar has a **project filter**: other projects fade, and Overdue and the Pool show only
  that project. The Pool's own project chips are gone.
- The rail marks a project with overdue work with a red dot; its tooltip gives the counts. Pinned
  projects show a thin progress bar.
- Task rows show where a task came from ("from Sep 26 log"), **P1–P3** priority, and its milestone.
- Wording: "quest" is now "task" everywhere you'd see it; a task's **Section** field is **Project**.
- Overdue counts now agree everywhere: a task you've re-planned to a later day, or parked in the
  backlog, no longer counts as overdue in the rail and Today.

## What to test

- Open a project. Check the header's health line against its tasks, change the status from the
  menu, pin and unpin, and use **⋯ → Open tasks in Calendar**.
- Put a project **On ice** with dated tasks and choose **Pause due dates**. Check its tasks leave
  Today, Overdue and the Calendar's Pool, and appear under **Paused projects** in the List. Set it
  back to Active and check they return.
- Mark a project **Done** with open tasks. Try each choice, and check the close-out note.
- On **Tasks**, group by Milestone. Add, rename, move and delete a milestone. Drag tasks between
  milestones, then between Status and Due groups. Use **Undo**.
- Add tasks with `@fri` and `^` from the List, a project's Tasks tab and its Overview.
- Open the Projects **Timeline** and click a ◆.
- Open a project that used the Board: it should open on Overview (or Tasks), with no Board.
- Filter the Calendar to a project, then clear it.
- Sign in on a second device and check milestones and paused projects sync.

## Known issues

- **Older versions still show the Board** for projects that used it, and don't know about paused
  due dates or the new milestone features. Milestones created here show there.
- "Complete all" when finishing a project marks tasks done one at a time; with many tasks it takes a
  moment.
- The Notes tree's project menu still says "section" (**Open section**, **Rename section**).
- The phone's project screens are unchanged.
