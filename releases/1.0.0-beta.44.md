# 1.0.0-beta.44 — Times and typed dates follow your settings

A batch of small fixes that had been written down during the code clean-up.

## What's new

- **Times follow the Time format setting everywhere.** With 24-hour time chosen, you no longer
  see AM / PM in the Activity log, a project's activity, the "saved" time under a note, the sync
  line in **Settings → Account**, or the date-and-time stamps in About, Account and a template's
  "Updated" tooltip.
- **A date typed with slashes is read in the order of your Date format setting.** With a
  day-first format, `5/10` after `@` in a task (or in the command palette) is 5 October. A date
  that only works one way round, such as `25/12`, is read that way under either setting.
- **Notes tree, Templates section:** the arrow keys now stop on template folders; Right opens
  one, Left closes it and then moves up to Templates. A template folder whose parent folder is
  missing, or has not synced yet, shows at the top of Templates instead of disappearing along
  with its templates.
- Under the hood: unused code removed (including a weekly-review page that could not be
  reached), saved settings come back in one consistent shape, and the notes tree saves which
  folders are open once per change instead of twice.

## What to test

- Set **Settings → Time format** to 24-hour, then look at the Activity log, a project's
  Activity tab, the "saved" line under a note, and **Settings → Account**. Switch back to
  12-hour and check they follow.
- Set **Date format** to a day-first format. Add a task with `@5/10` and check it lands on
  5 October; try `@25/12` and `@12/25` under both date formats. Do the same from quick capture,
  the calendar's add box and a project's task list.
- In the notes tree, make a template folder with a template in it. Walk the Templates section
  with the arrow keys; open and close the folder with Right and Left.
- Expand and collapse folders in the notes tree, quit and reopen: they are as you left them.
- Change a setting (theme, date format), quit and reopen: it held.
- Archive a note from the tree's right-click menu and restore it.

## Known issues

- `F2` and `Delete` do nothing on a template or template folder in the notes tree; use the
  right-click menu.
- The open items from beta.19 still stand.
