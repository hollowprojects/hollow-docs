# 1.0.0-beta.58 — Stored streaks are gone

Hollow used to keep two streak counts besides each habit's own, and showed neither of them
anywhere. This release removes both, and the place they were stored.

## What's new

- **The global streak is gone.** It was a single "days in a row you did anything" count. The
  screen that showed it was removed long ago, but the app kept updating it every time you
  completed something or saved a note. It no longer does.
- **The stored streak for repeating tasks is gone.** Each chain of a repeating task kept its own
  count, updated whenever you completed one. It was never shown anywhere.
- **The streaks table is removed**, from this device and from the cloud. Nothing was left that
  used it.
- **Habit streaks are unchanged.** They were never stored: each habit's streak is worked out
  from the days you kept it, so correcting a past day still corrects the streak.
- For people working on Hollow's code: an editor-only TypeScript setting was fixed, so the
  editor no longer reports a false "cannot write file" error on every JavaScript file. The app
  itself is built the same way as before.

Nothing here changes what you see. Completing a task or a habit, and creating or editing a
note, each do a little less work.

## What to test

- Complete a repeating task: the next one appears as before.
- Delete a habit: it goes, and nothing else changes.
- Keep a habit today and check its streak count goes up; un-keep it and check it goes back.
  Correct a past day in the habit's five-week grid and check the streak follows.
- Sign in and check sync still works: change something on one device and see it arrive on
  another, and check the sync indicator settles instead of staying on an error.
- Complete a task, complete a habit, create a note and edit one: all as before.

## Known issues

- A copy of Hollow older than beta.58 that is signed in will fail to upload its streak rows
  until it is updated, and its other changes wait behind them. Update every device to
  beta.58 or later.
- The open items from beta.19 still stand.
