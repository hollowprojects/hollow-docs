# 1.0.0-beta.20 — Under the hood: one test gate

Nothing in this release changes how Hollow looks or behaves. It is the first of a series of
housekeeping releases that follow a code review of the whole app on 1 October. This one makes sure
every check that used to run only on the build server now also runs on the developer's machine
before a change is committed, and adds a linter that enforces the project's own code style and its
one hard architectural rule (the screen code never talks to the database directly).

If you are testing, treat this as a regression release: the question is whether anything that
worked in beta.19 stopped working.

## What's new

- Nothing visible. No setting, screen, shortcut or file format changed.

## What changed underneath

- A single test gate, identical on the developer's machine and on the build server.
- A linter with the project's existing style baked in, plus a rule that stops screen code from
  importing database or sync layers by mistake.
- The TypeScript compiler now rejects unused variables and imports. Clearing the backlog of those
  removed some dead code, including an unfinished "remind at" field in the habit editor that was
  never shown and never saved anything.
- Node 24 is the pinned toolchain.

## What to test

- Open the app, open a few notes and tasks, complete a habit for today, open the Calendar and the
  Habits grid. Everything should look exactly as it did in beta.19.
- Open the habit editor (click a habit's name) and check the fields you use are still there.
- If you are signed in: make a change on one device and check it arrives on the other.

## Known issues

- None new. The open items from beta.19 still stand.
