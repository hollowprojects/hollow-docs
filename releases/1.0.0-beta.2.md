# 1.0.0-beta.2 — the app is now called Hollow

This release is a rename. Request is Hollow: same app, same data, new name, new icon, and a new
theme built from the brand colours.

## What's new

- **New name and icon.** Hollow, with a crescent mark — a ring holding a single gold point.
- **A Hollow theme.** Settings → Appearance has a fourth option, in ink, cream and gold. It has
  both a light and a dark mode like the others, and Light / Dark / Auto still applies.
- **Your data moves itself.** The first launch after updating carries your notes, planner and
  settings across to the new folder. Nothing is copied or duplicated; the folder is moved.

## What to test

1. **Your notes are still there.** Launch, and check the Notes tree, Planner, habits and projects
   all look the way you left them. This is the important one — everything else is cosmetic.
2. **The new theme.** Settings → Appearance → Hollow. Try it in both light and dark mode, and
   check the things that use accent colour: task chips, the sync pill, project dots, overdue
   markers.
3. **The icon.** Check it in the taskbar, the Start menu and Explorer. It should be legible when
   small, not a smudge.
4. **Backups.** Settings → Backup: export a bundle and restore it. Older backups made under the
   Request name still restore — the file format did not change.

## Known issues

- **You may have two apps installed.** Hollow installs alongside Request rather than upgrading it,
  because the installer identity changed. Your data has moved to Hollow; **uninstall "Request
  Beta"** from Windows Settings → Apps once you have confirmed Hollow opens with your notes intact.
- The old data folder is left behind if the move fails for any reason (for example if the folder is
  open in another program). If Hollow starts up empty, close everything and relaunch before doing
  anything else — and report it rather than re-entering notes.
- The name change does not touch anything in the cloud. Sync, your account and your synced data are
  unaffected.
