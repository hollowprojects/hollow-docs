# Request 1.0.0-beta.0

**The first installable build.** Windows only, for the author's own daily use. Everything in
this release is about being able to run Request as a real app, keep working offline, sign in
when you are ready, and tell us when something breaks.

## What's new

- **Installers.** An MSI installer and a zip you can run from any folder. The app is named
  *Request Beta* and keeps its data in its own folder, so it runs beside a development copy.
- **Start local, sign in later.** The first screen offers *Use this device only for now*. Work
  without an account; when you choose *Settings → Account → Sign in to sync*, everything you made
  moves into the account and uploads. A toast tells you how many items moved.
- **Continue offline.** If your sign-in has expired while you are offline, the sign-in screen
  offers to open your data anyway. Changes wait and upload when you are back.
- **Sync indicator.** A pill in the top strip appears only when sync has something to say:
  syncing, offline with changes waiting, or stalled. *Settings → About* has the full line.
- **Bug reporter.** `Ctrl+Shift+B`, the rail's *Report a bug*, the palette, or *Report this* on a
  crash screen. It attaches the build, platform and recent errors, never your notes. Offline it
  saves the report as a note in a *Beta feedback* folder instead.
- **About.** Version, exact build, platform, account mode, sync state and data folder, in one place.
- **User guide** (`F1`, *Help* in the rail). This guide, inside the app, with *What's new* and a
  *Report an issue with this page* button on every page.

## Also in this build

The core planning work from the days before: one definition of *Late* across List, Calendar and
the day glance; do-date changes always through placement so tasks never sit in two groups; the
`#project @date >parent` capture shorthand everywhere tasks are added; note templates managed
from the explorer; the end-of-day *wrap up the day* sheet; Calendar Agenda view with add rows on
every day; This week / Next week / Later groups in the List.

## What to test

1. Install, choose *Use this device only for now*, and use the app for real for a few days.
2. *Settings → Account → Sign in to sync*. Watch for the "Moved N local items" toast and the
   sync pill counting down to zero.
3. Sign in on a second computer and confirm everything arrived.
4. Put the machine in airplane mode, edit, relaunch, come back online. Nothing should be lost.
5. Anything odd: `Ctrl+Shift+B`.

## Known issues

- Updates are manual: install the new MSI over the old one, or replace the zip's folder.
- The Windows installer is not code-signed; SmartScreen will warn once.
- Programs & Features shows `1.0.0.0` for the MSI; the real version is in *Settings → About*.
- Mobile is not part of this build.
