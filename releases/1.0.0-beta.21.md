# 1.0.0-beta.21 — Under the hood: dead code removed

The second housekeeping release after the 1 October code review. This one deletes code that
nothing reached any more, including a whole background feature that never had a screen. Two
small things are visible; the rest is a regression release like beta.20.

## What's new

- **A new task is called "New task"** until you give it a name. It used to say "New quest", a
  word from an older version of the app.
- Two validation messages about habits also say "habit" instead of "quest".

## What was removed

- **The Chronicle.** An older version of Hollow kept a diary of your streaks, completed tasks
  and project milestones in the background, with the idea of showing a weekly narrative. The
  screen for it was never built, so the diary was written and never read. The background job,
  its data tables and its sync rules are gone. **Your notes, tasks, habits, projects and streaks
  are untouched.** If you are signed in, the two tables are dropped from the cloud database as
  part of this release; nothing you can see depended on them.
- An unused task form, an unused Today row, unused form controls and about 170 stylesheet rules
  that no screen used.

## What to test

- Create a task from the command palette or the List with no name and check it reads "New task".
- Open the app, the Calendar, the Habits grid, a project, a note and the Day companion. Everything
  should look as it did in beta.20.
- Complete a habit for today and check the streak count still rises; undo it and check it falls.
- If you are signed in: make a change on one device and check it arrives on the other, then
  restart both and check they still sign in and sync. This release changed the sync rules.

## Known issues

- None new. The open items from beta.19 still stand.
