# 1.0.0-beta.25 — Under the hood: the editor in three pieces

The first of the restructuring releases that follow the 1 October code review. The earlier ones
cleaned up; these take the largest source files apart, one seam at a time, so each piece can be
read and tested on its own. This one is the note editor: its toolbar and its Markdown source view
now live in their own files. The editor should look and behave exactly as it did.

## What's new

- **Save works with Caps Lock on.** `Ctrl+S` in the normal editor view did nothing while Caps Lock
  was on. It saves now.
- `Ctrl+Alt+S` saves in the Markdown source view too, as it already did in the normal view.
- Nothing else is meant to have changed.

## What to test

This release is all about the editor, so please use it hard:

- Type, format with the toolbar (bold, italic, headings, lists, task lists, table, code block,
  link), and check each button does what it did.
- Narrow the window until the toolbar folds its buttons into the overflow menu, and use a
  button from that menu.
- Switch to the Markdown source view and back. Edit in the source view, use `Ctrl+B` / `Ctrl+I`
  there, switch back, and check the change is in the note.
- Press `Ctrl+S` in each view and check the status line at the bottom says saved.
- Insert a template variable and a link from the toolbar.

## Known issues

- None new. The open items from beta.19 still stand.
