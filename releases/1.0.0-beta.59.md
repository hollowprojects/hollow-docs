# 1.0.0-beta.59 — The sidebar opens in the pane you are in

With the main area split, clicking a row in the sidebar used to go looking for that screen
in the other panes first. If it found it, it switched over there and took the focus with it.
Because the List, the Calendar and Habits are all the Planner, clicking **Calendar** went to
whichever pane held a Planner tab — often not the one you had just clicked into.

## What's new

- **A sidebar click opens in the focused pane.** Click into a pane, then click **Today**,
  **List**, **Calendar**, **Habits**, a project or a note: it opens there. A copy open in
  another pane is left as it is. The same goes for the command palette and for links inside a
  screen.
- If the pane you are in already has a tab for it, you still switch to that tab — nothing is
  opened twice in one pane.
- The **OPEN** marker is unchanged: it still shows that a row is open somewhere.
- One thing still looks for a List you already have open: a link that shows you a single
  task in the List selects it in the List beside you, when there is one.

- **The Layout menu lists only layouts that exist.** The six **Empty slot** rows are gone. A key
  with no layout on it still works: press it and the **Save layout** box opens on that key.
- **One layout comes with Hollow now: Daily log**, on `Ctrl+1` — today's page with the day's
  tasks and habits beside it. It is the layout that was called **Write**. **Plan**, **Research**
  and **Review** are no longer shipped; a copy you had changed with **Update** is kept. To have
  one again, arrange the panes and use **Save as new layout…** (the user guide lists what each
  was).
- **Notes in a project show in the sidebar.** A project used to appear in the **Notes** tree only
  once its project page was written, so notes filed in, or linked to, a project without a page
  had no row anywhere. A project now appears as soon as it has a note of any kind.
- **A template looks like a note.** The template tab has the note's layout: the name where the
  title is, the body on the same page width and typeface, the toolbar on hover, and save state
  on a status line under the text. Tags, folder and title sit in a short block above the body;
  **{{ }} variables** and **Delete** are on the status line.
- **Calendar, light themes:** the hour lines in today's column are visible again.
- **Sidebar footer:** the Help, Report a bug and Settings icons are larger.

## What to test

- Split the main area with the List on one side and a note on the other. Click into the
  note, then click **Calendar** in the sidebar. The Calendar replaces the note; the List
  stays the List. **Back** returns the note.
- Do the same from a layout with three or four panes: the pane you clicked last is the one
  that changes.
- Open the same note in two panes by clicking it in the sidebar from each. The header says
  **Open in both panes · edits sync**, and typing in one shows in the other.
- With a Task open beside the List, click into the Task, then click **Habits** in the
  sidebar. Habits opens in that pane. Click a task in the List again: the Task comes back
  beside it.
- **Ctrl**-click, **Alt**-click and the right-click **Open…** menu behave as before.

- Open the **Layout** menu on a new profile: **Daily log**, then the five shapes. Press `Ctrl+3`:
  the **Save layout** box opens with **3** chosen. Save, and the layout is in the menu with its key.
- If you had **Plan**, **Research** or **Review** on a key, that key now offers to save a layout.
  **Manage layouts…** → **Restore defaults** puts Daily log back on `Ctrl+1`.
- Make a project, do not write its page, and add a note from its **Notes** tab. The project's
  folder appears in the sidebar with that note. Link a journal page to another project with no
  page (Properties → Project): that project appears too, with the page under **Linked**.
- Open a template from the **Templates** group. Compare it with a note beside it: same title
  position, same text width. Rename it, add a tag, set a **Title**, and watch the status line go
  **Unsaved** → **Saved**. **Use ▾** and **Default for ▾** work as before.
- In a light theme, open **Calendar** on the week or day view and check today's column.

## Known issues

- The open items from beta.19 still stand.
