# 1.0.0-beta.38 — Under the hood: less code, stricter checks

Nothing in the app changes. This release removes code that nothing used and tightens the
automated checks so the same kind of leftover cannot build up again.

## What's new

- Nothing visible.

## What changed underneath

- **About 1,250 lines of unused code are gone**: old backlog filters, helpers for a side panel
  that no longer exists, leftovers from the gamification era, and deprecated aliases. Nothing
  referred to any of it. From now on, code that nothing uses fails the automated checks instead
  of being reported as a warning.
- **The screen code is fully walled off from the database layers.** It could still borrow type
  definitions from them; those borrowings were moved out earlier, and the rule now forbids them.
- **Tests look at the app the way a person does.** Fifteen more test files find things by their
  role and label instead of by internal style names (those lookups dropped from 578 to 217).
  That work produced a list of places where a screen reader has nothing to hold on to; fixing
  them is a release of its own, coming up.
- A test that fails can no longer leave the app running in the background and disturb the tests
  after it.

## What to test

- This removed a lot of code that should have been unreachable. Please use the app broadly:
  Today, List, Calendar, Habits, a project and its tabs, notes and templates, the command
  palette, Settings, export and backup. Report anything that worked in beta.37 and does not now.

## Known issues

- None new. The open items from beta.19 still stand.
