# 1.0.0-beta.27 — Under the hood: the desktop's message handlers, sorted

The third restructuring release. The single file that answered every request from the screen to
the database (nearly two thousand lines) is now sixteen small files, one per area, and the
decisions that used to live inside it moved to the service layer where they can be tested and
shared with the phone. Nothing should look different.

## What's new

- **On the phone, finishing the last task of a milestone now completes the milestone**, as it
  already did on the desktop. The rule lived in the desktop-only layer; it is shared now.
- **Deleting a task template reports failure.** The delete used to be fired off without waiting,
  so if it failed nothing told you. It waits now and shows an error if it could not delete.
- Nothing else is meant to have changed.

## What to test

Everything that saves or loads passes through the reorganised layer, so a broad pass is the
useful one:

- Create, edit, complete and delete a task; complete the last open task of a project milestone
  and check the milestone completes.
- Create and delete a note; move one between folders; delete a folder that holds notes.
- Open Settings → Account & data: export a backup; install the starter templates.
- Create a task template, use it, delete it.
- With "append to note" on (Settings → Planner), complete a task and check the line appears in
  the note with today's date.
- Open the Day companion and check the day's activity lists what you just did.
- Change the journal title format in Settings → Writing and apply it to existing pages.

## Known issues

- None new. The open items from beta.19 still stand.
