# 1.0.0-beta.19 — Settings, regrouped

The Settings window has been rebuilt. It has six groups named for what they are about, controls
that show their real values, and a preview where a preview helps. Two things that were sections of
Settings have moved to where they are more use: the activity log is now a tab, and the list of
keyboard shortcuts is a page of the guide. Nothing you had set has changed.

## Read this first: where things went

| Was in | Is now in |
|---|---|
| Appearance | **Appearance** |
| Editor | **Writing** |
| Notes & links → Journal title, quick-capture folder | **Writing** |
| Notes & links → Journal month grouping | Right-click the **Journal** heading in the sidebar → **Month labels** |
| Notes & links → When you complete a task, append to | **Planner** |
| Regional | **Planner** |
| Modules → Show Projects | **Desk** |
| Modules → Reopen tabs on launch | **Desk** → **On launch, open** |
| Account, Data | **Account & data** |
| Activity log | A tab: **Activity log** in the command palette, or **Open Activity log ›** in **Account & data** |
| Shortcuts | The guide's **Keyboard shortcuts** page: the button in **About**, or the command palette |

- **If you had turned off Reopen tabs on launch**, Hollow now opens the **Write** layout: Today
  with the Day beside it. Before, the Day only came back if it was open when you quit. To change
  what opens, go to **Settings → Desk → On launch, open**.
- **The activity log is not in Settings any more.** It opens as a tab marked **LOG**, so you can
  keep it beside the note or task you are checking it against. How long history is kept is still a
  setting: **Keep history for**, under **Account & data**.

## What's new

### The window

- **Six groups**, each with a line saying what is in it: Appearance, Writing, Planner, Desk,
  Account & data, About. Desk is on the desktop only.
- **Choices you can read at a glance.** A setting with a few options shows them side by side with
  real values: a date as it will be written, a font size in pixels, `4:00 PM` against `16:00`.
  Anything you switch on or off is a switch on its own row with a line saying what it does.
- **Previews.** Appearance shows a day's title, some text, two tasks and two chips in your colours.
  Writing shows two paragraphs in the size, line height and spacing you chose. Both change as you
  change the settings.
- **What syncs is said once.** The line beside the title says settings follow your account; the
  few that stay on one device carry a small **THIS DEVICE** mark. If you are not signed in, it
  says everything is stored on this device.
- **The window keeps its size** as you move between groups.
- **It works on a phone-sized window**: the groups run across the top and each setting stacks.

### Account & data

- A card at the top shows who is signed in, whether sync is on, when it last synced and how many
  changes are waiting.
- Export, restore, import and starter templates are each a row with its button at the right.
- **Restore backup is greyed out while you are signed in**, and the row says why. It used to let
  you click and then explain.

### Desk

- **On launch, open**: your last session, or a layout you choose.
- **Layouts**: **Manage layouts…** and **Restore the four defaults**.
- **Sidebar**: Full, Icons or Hidden, the same three sizes as the button in the top bar.
- **Sidebar flyouts**: whether the panel beside the icon sidebar closes after you open something
  or stays. It is the same choice as the pin on the panel.
- **Focus mode hides**: tick what goes in Focus mode. The sidebar and the tab strips are ticked to
  begin with, which is how it has always worked. You can add the other panes of a split, the top
  bar and the word count.

### Writing

- **Journal template**: what a new day's page starts from. It is the same setting as **Default
  template** on the Journal heading in the sidebar.
- **Journal title** shows today's date in each format instead of a pattern.

### The command palette

- **Settings: Appearance**, **Settings: Writing** and the rest open Settings on that group. Typing
  a setting's name finds its group: *density*, *backup*, *font size*.
- **Activity log** opens the log as a tab.
- **Keyboard shortcuts** opens that page of the guide.

## What to test

- Open each group and change something. Close Settings, reopen it, and check it kept the change.
  Restart the app and check again.
- Change the theme, accent, mode and density, and watch the Appearance preview follow.
- Change the font size and line height, turn on **Highlight active line**, and watch the Writing
  preview follow. Then check a real note looks the same.
- If you are signed in: change **Time format** on one device and see it arrive on the other.
  Change **Interface size** and check it does *not* arrive.
- Set **On launch, open** to **A layout**, pick one, quit and reopen. Then set it back to **Last
  session** and check your tabs come back.
- Tick **The top bar** and **Word count** under **Focus mode hides**, open a note and press
  `Ctrl+.`. Check you can still move and close the window. Press `Esc`.
- With two notes side by side, tick **Other panes** and press `Ctrl+.` in one of them. Leave Focus
  mode and check the other pane is back as it was.
- Open the activity log from the command palette. Drag its tab to the side of a note.
- Right-click the **Journal** heading in the sidebar and change **Month labels**.
- Set **Journal template** in Settings, then check **Default template** on the Journal heading
  shows the same choice, and the other way round.
- Narrow the window as far as it goes with Settings open.

## Known issues

- The signed-in parts of **Account & data** (the status card, the greyed-out Restore) and the
  phone layout have been checked by automated tests and in a narrow desktop window, not on a
  signed-in account or a real phone.
- **Other panes** in Focus mode is new. If a split looks wrong after leaving Focus mode, report it
  and untick it in **Settings → Desk**.
- Settings has no search of its own. Use the command palette: type the name of the setting.
