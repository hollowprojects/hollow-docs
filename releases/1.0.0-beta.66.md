# 1.0.0-beta.66 — Faster, sturdier sync

Sync sends your changes up in batches now, and one change the server refuses can no longer hold
up everything you do after it.

## What's new

- **Big uploads take seconds, not minutes.** Hollow used to send every change to your account
  as its own request, one after another. It now sends a run of similar changes together. A large
  test account that took 53 minutes to upload now uploads in about half a minute. Everyday use
  feels the same, just quicker after a long offline stretch.
- **One bad change can't stall sync any more.** If your account refuses a change for good — for
  example, it points at something that no longer exists — Hollow sets that one change aside and
  carries on with the rest. Before, it would retry the same change forever and nothing after it
  would upload. A change set aside is listed in **Settings → About → Copy sync diagnostics**,
  marked **DISCARDED**, so you can report it.
- **An edit to something deleted on another device is no longer lost without a trace.** It is
  listed in the same diagnostics.
- **Long uploads keep working after an hour.** Sign-in stays fresh through a long upload instead
  of running out partway.
- **On the phone**, sync problems are now written to its log with the actual error, so they can
  be diagnosed. (The phone has not been tried on a real device yet.)

## What to test

- Make a few changes offline (a note, two tasks, a habit tick), go back online, and check the
  sync indicator settles on **Synced** and the changes appear on your other device.
- If the sync indicator ever shows a problem, open **Settings → About**, choose **Copy sync
  diagnostics** and include it in a bug report (`Ctrl+Shift+B`).

## Known issues

- If the first download on a new computer takes longer than a minute, Hollow opens anyway and
  your name and settings can be reset on that computer (from beta.65).
- The open items from beta.19 still stand.
