# 1.0.0-beta.47 — Under the hood: new notes and templates

The code that creates a new note (from the keyboard, the rail, the Notes screen, or a template)
and that opens templates as tabs has moved out of the large desk shell file into its own piece,
with its own tests. Nothing should look or behave differently.

## What's new

- Nothing you can see. Creating notes and opening templates now have 20 tests of their own, and
  the desk shell is a third smaller than it was at beta.38.

## What to test

Every way of making a note, since that is what moved:

- `Ctrl+N` with a note open: a new note appears beside it and opens. With a default template
  set on the folder or project, the template is applied and the "Blank instead" offer clears it.
- New note from the rail's **+** and from the empty Notes screen.
- New note from a template: from the picker, and from the command palette.
- Open a template from the notes tree: it opens as a tab. Create a new template: it opens in a
  new tab. Close a new template you never wrote in: Hollow offers to discard it.
- With a note open, use **Save as template**. On Today's page it should only explain why not.

## Known issues

- The open items from beta.19 still stand.
