# 1.0.0-beta.31 — One list of keyboard shortcuts

Until now each keyboard shortcut was checked by hand wherever it happened to be handled, about
fourteen places in all, and the text that tells you a shortcut (tooltips, menus, the guide) was
typed separately. The two could disagree, and one did. Shortcuts now live in a single table that
the handling, the on-screen labels and the guide's shortcuts page all read from.

## What's new

- **A wrong tooltip is fixed.** The day header's "Back to today" tooltip still said `Ctrl+1`.
  That key has opened a layout since beta.17. It now says `Ctrl+Shift+T`, which is the real key.
- **Shortcuts match exactly.** A shortcut now fires only for its own keys:
  - Holding an extra modifier no longer triggers it. For example `Ctrl+Alt+Shift+N` used to
    open Quick capture as if it were `Ctrl+Shift+N`, and `Alt+Shift+←` went back like `Alt+←`.
    Those accidental variants are gone.
  - On Windows the Windows key no longer stands in for Ctrl (`Win+K` used to open the palette).
  Every shortcut in the guide works as written, including `Ctrl+P` and `Ctrl+Shift+K` for the
  command palette.
- **The guide's Keyboard shortcuts page is checked automatically** against what the app does,
  so it cannot drift again. It now lists the four pane-focus keys and `Ctrl+1` to `Ctrl+4`
  individually.
- **The command palette is contained**, completing beta.30: if it fails it shows a message with
  Close instead of the whole-window error screen.

## What to test

Open Help (`F1`) → Keyboard shortcuts and try each one on the page. In particular:

- `Ctrl+K`, `Ctrl+P`, `Ctrl+Shift+K` (palette); `Ctrl+Shift+N` (Quick capture); `Ctrl+,` (Settings);
  `Ctrl+Shift+B` (Report a bug, also while typing in a note).
- `Ctrl+N` (new note); `Ctrl+W` (close tab); `Ctrl+Tab` / `Ctrl+Shift+Tab`; `Alt+←` / `Alt+→`.
- `Ctrl+1`–`6` (layouts); `Ctrl+Alt+S` (save layout); `Ctrl+Shift+T` (Today).
- `Ctrl+\` (sidebar); `Ctrl+Shift+\` (companion); `Ctrl+Alt+\` (split); `Ctrl+.` (Focus mode, `Esc` to leave).
- `Ctrl+Alt+Shift+arrows` (move between panes); `Ctrl+Alt+←` / `→` (previous / next day on Today).
- `Ctrl+Alt+T` in a note (template menu); `Ctrl+Shift+1` (Day beside); `Ctrl+Alt+I` (Properties beside).

If a shortcut you use has stopped working, tell us the exact keys: it may have been one of the
accidental variants.

## Known issues

- None new. The open items from beta.19 still stand.
