# 1.0.0-beta.61 — Groundwork for a second sample dataset

Nothing in this release changes what you see. It prepares the tools Hollow is developed with for a
second, much larger sample dataset, used to check that the app stays fast with years of notes and
tasks in it.

## What's new

- For people working on Hollow's code: the sample-data picker in the developer-only **Debug**
  settings now loads whichever dataset is chosen in it. It used to load the one built-in dataset
  whatever the menu said, which only mattered once a second dataset existed. The button now reads
  **Load dataset**, and a line under the menu says what the chosen dataset is for.
- For people working on Hollow's code: the command that moves the sample dataset's dates to today
  had stopped finding what it rewrites a few releases ago, and works again.

The **Debug** settings exist only in development builds, so the copy of Hollow you test with has
nothing new to see.

## What to test

- Nothing new. Use Hollow as you normally do: open today's page, add and complete a task, keep a
  habit, and check sync still settles if you are signed in.

## Known issues

- The open items from beta.19 still stand.
