# 1.0.0-beta.4 — Density

One thing in this release. Hollow now lets you choose how tightly rows stack, so you can fit more
on screen without shrinking the text.

## What's new

### Density

- **Settings → Appearance → Density**, with three settings: Compact, Comfortable and Spacious.
  Comfortable is the default and is exactly how Hollow looked before, so nothing changes unless
  you go looking for it.
- **It changes spacing, not size.** Compact tightens the gaps around rows in the Planner's lists,
  the note tree, the left rail, the day's task list and the habits table. The text stays the size
  it was. If you want everything bigger or smaller instead, that is **Interface size**, just below
  it in the same section.
- **It follows your account** to your other devices, unlike Interface size, which stays on the
  computer you set it on because it depends on the screen you are sitting at.
- **Rows stay tappable on a phone.** Compact is deliberately gentler on the mobile app, so a
  Compact you chose on the desktop does not leave you with rows too small to hit.

## What to test

1. **Comfortable is unchanged.** Before touching anything, look at the Planner list, the note tree
   and the rail. This release should look identical to beta.3 until you change the setting. If
   anything looks different at Comfortable, that is a bug and worth reporting.
2. **Compact, everywhere.** Switch to Compact and walk the Planner (List, Calendar, Habits), the
   Notes screen with the tree open, and the day's task list in the sidebar. You are looking for
   rows that overlap, text that touches an edge, or anything that has collapsed to nothing.
3. **Spacious.** Same walk. Rows should breathe, not drift apart into unrelated blocks.
4. **Text size should not move.** Switch between all three and watch a note title or a task name.
   The spacing around it changes; the letters do not.
5. **Density and Interface size together.** Set Interface size to 125% and Density to Compact.
   Large text in tight rows is the intended combination — check it still lays out sensibly.
6. **It sticks.** Choose Compact, close Hollow, reopen it. It should come back Compact with no
   visible jump from Comfortable on the way in.

## Known issues

- Density covers the app's chrome — lists, trees, rails and sidebars. It deliberately does not
  change spacing **inside a note**; that already has its own controls under Settings → Editor
  (line height, paragraph spacing, list spacing).
- Controls like checkboxes and tabs keep their size at every density. Shrinking them would make
  them harder to hit without fitting any more rows on screen.
