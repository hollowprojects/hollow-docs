# 1.0.0-beta.24 — Under the hood: the tests catch more

The fifth housekeeping release after the 1 October code review. Nothing in the app changes. This
one is about the automated tests that run before every change is accepted: they now cover the
parts of Hollow that had none (the database upgrade chain, the desktop's internal messaging
contract, the phone bridge, the user-scoping layer), and they run faster and more reliably.

## What's new

- Nothing visible in the app, but one fix matters if you have an old database: **a database
  created before the beta (with tasks in it from before September's status rename) could fail
  to upgrade and leave the app unable to start.** The new upgrade-chain test found it; the
  upgrade step is fixed. Fresh beta installs were never affected.
- Three desktop messaging channels that nothing used were removed (206 remain).
- Three small bugs the new tests exposed are fixed: a signed-in account whose profile already
  existed came back without its display name on one path; restoring a backup made before May
  (one without the account column) failed its preview instead of matching by content; and a
  reminder that no longer exists now reports "not found" rather than a generic error.

## What changed underneath

- The full database upgrade chain, from an empty file to the current version, runs as a test.
  So does each of the last five upgrades on its own.
- The list of desktop messaging channels is checked against the preload bridge, the type
  declarations and the documentation automatically, instead of a hand-maintained list of 49.
- The phone's data bridge is checked for parity with the desktop's.
- The user-scoping layer, the service container, nine repositories and four services that had
  no tests now have them.
- Tests share one set of fixtures and one harness; about forty private copies are gone. Nineteen
  tests that waited on the real clock (up to one and a half seconds each) now use a fake one.
- A coverage summary is printed on every build server run so the parts without tests stay
  visible.
- **Screen readers get a little more.** Converting the tests to query the screen the way a reader
  does turned up a few gaps, now closed: the editor announces itself as a text box, toasts are
  announced when they appear, the Projects and Notes sections of the sidebar are named, and a
  few decorative glyphs no longer read as part of a button's name.

## What to test

- Nothing specific. Use the app as usual and report anything that worked in beta.23 and does
  not now.

## Known issues

- None new. The open items from beta.19 still stand.
