# 1.0.0-beta.55 — Under the hood: getting around the desk

The code that moves you between screens (opening a screen or a note, stepping back and forward,
opening a note beside another) has moved out of the large desk shell file into its own piece,
with its own tests. Nothing should look or behave differently. The desk shell is now half the
size it was at beta.38.

## What's new

- Nothing you can see. Navigation now has 15 tests of its own.

## What to test

Moving around, since that is what moved:

- Open Today, List, Calendar, Habits, a project and a note from the sidebar and from the
  command palette.
- Step back and forward with the keyboard shortcuts and with a mouse's back and forward buttons.
  Each step returns to the screen and the day you were on.
- Delete or archive a note, then step back through history: the missing note is skipped.
- Open a note beside another (from a note's menu or by dragging a tab). Asking for a note that
  the other pane already shows moves focus there instead of opening it twice.
- Write in a note and navigate away without waiting: the text is saved.

## Known issues

- The open items from beta.19 still stand.
