# 1.0.0-beta.16 — Links you can actually add

A fix release. On the desktop, the editor's two **Link** buttons did nothing at all: no box, no
link, no message. They do now.

## What's fixed

- **Adding a web link works.** Select some text and press **Link** (↗) in the bubble menu, or
  **Insert link (URL)** in the toolbar (under **⋯** when the toolbar is narrow). A small box opens
  by the button; paste or type the address and press **Enter**.
- **You don't have to type `https://`.** `example.com/page` becomes a web link and
  `name@example.com` becomes a mail link. Anything that isn't a web or email address is refused,
  with a line saying so.
- **Editing and removing.** Select a link and open the box again: the address is filled in. Change
  it and press **Enter**, or clear it (or press **Remove link**) to take the link off. **Esc**
  closes the box and leaves the page as it was.
- The box also works in **Markdown source** view.

## What to test

- Select a word, press **Link** in the bubble menu, type `example.com`, press **Enter**. The word
  should become a link; hovering shows where it goes, and clicking opens your browser.
- Make the window narrow so **Insert link (URL)** moves under **⋯**, and add a link from there. The
  box should open by the **⋯** button, not off-screen.
- Select the link and press **Link** again: the address is there. Clear it and press **Enter**:
  the link is gone and the text stays.
- Type `not a link` in the box and press **Enter**: it should say so and stay open.
- Open the box and press **Esc**: nothing changes, and you can keep typing in the note.
- Switch to **Markdown source**, select a word, add a link: it should be written as
  `[word](https://…)`.

## Known issues

- Two Today panes always show the same day, and two Planner panes share one selected day.
- Two devices editing the same project's milestones or status while one of them is offline can
  lose one of the edits. See the project follow-ups plan.
- The phone's project screens are unchanged, and the phone can't yet start in local mode.
