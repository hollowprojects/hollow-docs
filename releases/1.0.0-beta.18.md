# 1.0.0-beta.18 — Templates open in a tab, and folders can start notes from one

Note templates are now part of how a note begins, not a side panel you visit. A template opens in
a tab like a note. A folder can name the template its new notes start from, and so can your
journal. An empty note offers a template from its header. The phone app follows the same rules for
new notes and journal pages, but still has no template editor.

## Read this first: what changed under you

- **New note can now start from a template.** If a folder, its parent or its project has a default
  template, **New note** in that folder uses it — including `Ctrl+N` while you are reading a note
  there. Until this version only a project's **+ New note** button did. If you had set a project's
  **Default note**, you will see this straight away.
- **A message offers the way back.** After a default is applied it says **Created from** *the
  template* with **Blank instead**. **Blank note** in the menus and **New blank note** in the
  command palette skip the template.
- **The template editor is a tab, not a sheet over the screen.** Click a template in the sidebar's
  **Templates** group and it opens beside your notes, marked **TPL**.
- **Your journal keeps its template.** A template named *Daily* still seeds new journal pages, as
  before. You can now choose a different one.
- **New note from template…** in the folder menus is now **New from template**, with your
  templates listed right there. The old picker is under **Browse all…**.

## What's new

### Templates as tabs

- A template opens in a tab you can split, move and close like any other, and it comes back when
  the app reopens your tabs.
- **Use ▾** makes a note from it: here, in a new tab, to the side or below. **Insert into focused
  note** puts its text into the note you were last writing in, when that note is open in another
  pane.
- **Default for ▾** sets it as the default for the journal, a folder or a project.
- **New template** creates the template straight away as *Untitled template*. Close it untouched
  and it is removed again.

### What a template can set

- **Title**: a title for new notes, with variables — `New character {{date}}`. Two notes that
  would get the same title are numbered.
- New variables: `{{longdate}}`, `{{weekday}}`, `{{week}}`, `{{project}}` and `{{cursor}}`, which
  marks where the caret starts in the new note. `{{title}}`, `{{date}}`, `{{time}}` and
  `{{folder}}` work as before.
- Variables show as small tokens in the template. Type `{` to pick one.

### Defaults

- Right-click a folder → **Default template**: a template, **Inherit** (use the parent folder's,
  then the project's) or **None** (no template here, whatever the parent says).
- Right-click the **Journal** heading → **Default template** for the journal's.

### Where a note is born

- An empty note has a **Template ▾** button in its header, and `Ctrl+Alt+T`. It fills the note you
  are in. The button goes once you type and comes back if you empty the note.
- A journal day you have not written yet shows its template in grey. Click the page to start from
  it. **Change ▾** picks another template for that day; **Start blank**, or `Alt`-click, starts
  empty.
- Right-click a note → **Save as template**.

### The Templates group

- Templates can be filed in folders: right-click the **Templates** heading → **New folder**, then
  **Move to** on a template.
- A template's menu has **Use**, **Set as default for**, **Rename** and **Duplicate**.
- The journal's template is tagged **DAILY**.

### Fixed

- **Insert variable** in the template editor's toolbar did nothing. It inserts the variable now.

## What to test

1. Open a template from the sidebar. It should open as a tab, with no sheet over the screen.
   Split it beside a note.
2. Give a folder a default (**Default template**), then make a note there with `Ctrl+N` and from
   the folder's menu. Both should start from the template and offer **Blank instead**.
3. Click **Blank instead**. The same note should empty; no second note should appear.
4. Set a subfolder to **None** and make a note in it. It should be blank.
5. Put `{{cursor}}` in a template, make a note from it, and start typing. The text should land
   where the marker was, and the note should not contain the word *cursor*.
6. Give a template a **Title** and make two notes from it on the same day. The second should end
   in *2*.
7. Step to a journal day you have not written. Check the grey preview matches the page you get
   when you click. Try **Start blank**.
8. In an empty note, press `Ctrl+Alt+T` and pick a template.
9. Delete a template that is a folder's default. A message should say it is no longer the default,
   and **New note** in that folder should be blank again.
10. If you use two devices: set a folder's default on one and check it arrives on the other.

## Known issues

- **Insert into focused note** needs the note open in another pane. With one pane it says so and
  does nothing.
- An empty subfolder inside a folder that has no notes at all is not shown in the tree, so you
  cannot right-click it to set its default until the folder has a note.
- The built-in templates under **Browse all…** (*Meeting notes*, *Daily journal*, *Reading
  notes*) cannot be a default. Make a note from one and use **Save as template** first.
- A template keeps no count of how many notes were made from it.
- Notes cannot yet carry custom properties, so a template sets only a title, tags and a folder.
- The phone has no template editor and no **Template ▾** button. It does use folder defaults and
  the journal's template.
- A folder's or the journal's default has not been checked across two devices.
- Two devices editing the same project's milestones or status while one of them is offline can
  lose one of the edits. A project's **Default note** is stored the same way.
