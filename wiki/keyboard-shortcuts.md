# Keyboard shortcuts

Written for Windows. On a Mac, `Ctrl` is `⌘` and `Alt` is `⌥`; `Alt+←` / `Alt+→` are also
`⌘[` / `⌘]`.

## Everywhere

| Action | Keys |
|---|---|
| Command palette / search | `Ctrl+K` (also `Ctrl+P`, `Ctrl+Shift+K`) |
| Help (this guide) | `F1` |
| Quick capture | `N` when not in a text field, or `Ctrl+Shift+N` |
| New note next to the one you are reading | `Ctrl+N` |
| Fill an empty note from a template | `Ctrl+Alt+T` |
| Report a bug | `Ctrl+Shift+B` |
| Settings | `Ctrl+,` |
| Today | `Ctrl+Shift+T`; press again on Today to jump back to today's date |
| Open a saved layout (it replaces the panes and tabs on screen) | `Ctrl+1` to `Ctrl+6`; on an empty one, the **Save layout** box opens |
| Save as new layout… | `Ctrl+Alt+S` |
| Switch between open tabs | `Ctrl+Tab` / `Ctrl+Shift+Tab` (also `Ctrl` on a Mac) |
| Close the current tab | `Ctrl+W` |
| Split the main area in two, or fold every pane back into one (more layouts: the **Layout** button) | `Ctrl+Alt+\` |
| Move to the pane to the left, right, above or below | `Ctrl+Alt+Shift+←` / `Ctrl+Alt+Shift+→` / `Ctrl+Alt+Shift+↑` / `Ctrl+Alt+Shift+↓` |
| Open something to the side | `Alt+click` it |
| Open something in a new tab | `Ctrl+click` it (not in the Notes tree, where `Ctrl+click` selects) |
| Back / forward through the current tab | `Alt+←` / `Alt+→`, or the mouse's back / forward buttons |
| Show or hide the left sidebar (it comes back full or as icons, whichever you last had) | `Ctrl+\` |
| Show or hide the companion (the tab beside the screen) | `Ctrl+Shift+\` |
| Day to the side | `Ctrl+Shift+1` |
| Properties to the side (follows the note you are writing in) | `Ctrl+Alt+I` |
| Close a dialog, menu or the palette | `Esc` |

`Ctrl+Shift+T`, `Ctrl+N` and back / forward act on the focused pane when the main area is split.

`Ctrl+1` starts on **Daily log**, the layout that comes with Hollow. `Ctrl+2`, `Ctrl+3`, `Ctrl+4`,
`Ctrl+5` and `Ctrl+6` start empty: press one and the **Save layout** box opens on that key.
Which layout sits on which key is yours to change, on each computer separately: see
[Saved layouts](tabs-and-split.md#saved-layouts). The Planner has no key of its own; open
**List**, **Calendar** or **Habits** from the sidebar or the command palette.

Some things have no key of their own but are one search away in the command palette (`Ctrl+K`):
**Rail: Show**, **Rail: Icons only** and **Rail: Hide** for the sidebar; **Layout: One pane**,
**Layout: Side by side**, **Layout: Stacked**, **Layout: Three panes** and **Layout: Four panes**;
your saved layouts by name (**Layout: Morning**); and **Toggle companion**. The sidebar button in the top strip steps through full, icons and
hidden with the mouse.

## On a note

| Action | Keys |
|---|---|
| Focus mode on or off (the pane you are in fills the window; the sidebar and tabs go too, or what you chose in **Settings → Desk**) | `Ctrl+.`; `Esc` also leaves it |
| Previous / next day, while Today is the open tab | `Ctrl+Alt+←` / `Ctrl+Alt+→` |
| Save now (it also saves as you type) | `Ctrl+S` |
| Move the current block up / down | `Alt+↑` / `Alt+↓` |
| Bold / italic / strikethrough / inline code | `Ctrl+B` / `Ctrl+I` / `Ctrl+Shift+S` / `Ctrl+E` |
| Highlight | `Ctrl+Shift+H` |
| Heading 1 / 2 / 3 | `Ctrl+Alt+1` / `Ctrl+Alt+2` / `Ctrl+Alt+3` |
| Bullet / ordered / task list | `Ctrl+Shift+8` / `Ctrl+Shift+7` / `Ctrl+Shift+9` |
| Code block | `Ctrl+Alt+C` |
| Page break | `Ctrl+Enter`, or type `=== ` on an empty line |
| Link to a note | type `@` |
| Slash commands | type `/` at the start of a line |

`Ctrl+Shift+B` always opens **Report a bug**, even in a note. For a blockquote, use the toolbar's
blockquote button, the `/` menu's **Quote**, or type `> ` at the start of a line.

## In a task list (Planner List, a project's Tasks)

With a row selected:

| Action | Keys |
|---|---|
| Move the selection | `↑` / `↓` |
| Open its detail beside the list | `Enter` |
| Open its detail in a new tab / to the side | `Ctrl+click` / `Alt+click` the row |
| Pick the task's milestone | `M` |
| Open its date menu | `D` |

## On a project page

| Action | Keys |
|---|---|
| Jump to the project's add-a-task box | `N` (instead of Quick capture) |

## In the Planner Calendar

With a task focused (click it, or `Tab` to it):

| Action | Keys |
|---|---|
| Move it a day earlier / later | `Alt+←` / `Alt+→` |
| Move a timed task an hour earlier / later | `Alt+↑` / `Alt+↓` |
| Give an all-day task a time (09:00) | `Alt+↓` |
| Unschedule it | `Delete` or `Backspace` |

These replace Back / Forward while a Calendar task has focus. Done tasks stay where they are.

## In the Notes tree

The tree is one stop for `Tab`: it lands on the open note's row (or the row you last used), the
arrow keys move from there, and `Tab` again leaves the tree.

| Action | Keys |
|---|---|
| Into / out of the tree | `Tab` / `Shift+Tab` |
| Move up / down | `↑` / `↓` |
| First / last row | `Home` / `End` |
| Next row starting with a letter | type the letter |
| Expand / collapse a folder (← on a closed one goes to its parent) | `→` / `←` |
| Open | `Enter` |
| Rename | `F2` |
| Delete (asks first) | `Delete` |
| Cut / copy / paste / select all | `Ctrl+X` / `Ctrl+C` / `Ctrl+V` / `Ctrl+A` |
| Multi-select | `Ctrl+click`, `Shift+click` |
| Clear the selection | `Esc` |

## In the command palette

| Action | Keys |
|---|---|
| Move | `↑ ↓` |
| Open / run | `Enter` |
| Open a note to the side | `Ctrl+Enter` |
| Close | `Esc` |

## Resize handles

For the edge of the left sidebar and the line between two panes (including a page and its
companion):

| Action | Keys (with a handle focused) |
|---|---|
| Narrower / wider (split line: move it) | `← →` (the split line also takes `↑ ↓`; hold `Shift` for bigger steps) |
| Minimum / maximum | `Home` / `End` |
| Reset to default | `Enter`, or double-click the handle |

Right-click the line between two panes for **Swap panes**, **Reset to “name”** (in a saved
layout), **Equalise** and **Close … pane** — see
[Tabs and the split view](tabs-and-split.md#layouts-one-to-four-panes).
