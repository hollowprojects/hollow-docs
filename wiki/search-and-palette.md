# Search and the command palette

One box does both. Open it with **Search…** in the middle of the top strip, or `Ctrl+K`. `Ctrl+P`
and `Ctrl+Shift+K` open it too.

## Searching

Start typing. Results update as you type and come from:

- **Notes**, matched on title and full text, with a snippet.
- **Tasks**, matched on title and description.
- **Days**: type a date — `2026-10-03`, `10/3`, `10/3/26`, `today`, `tomorrow` or `yesterday` — and
  the palette offers **Open log —** *that day* to jump to its daily note.

Use ↑ ↓ to move and Enter to open. Opening a task takes you to Planner → List with the task
open beside it; opening a note takes you to it in Notes. `Ctrl+Enter` on a note opens it to the side, in a
second pane.

Projects and folders are not search results themselves, but typing a project's name finds the
actions that go with it (below).

When you have typed something, two buttons sit under the results: **Create note from query** makes
a note titled with what you typed, and **+ Add as new task** opens Quick capture with it filled in.

## Actions

With the box empty, or when your text matches an action name, the palette lists actions:

| Action | What it does |
|---|---|
| New note | A note next to the one you are reading, from that folder's default template if it has one |
| New blank note | The same, without the template |
| New task | Quick capture in task mode |
| New project… | Asks for a name, then opens the new project on its Overview |
| New template | Starts a template and opens it in a tab |
| New note from template | Asks for a title, then a template |
| Save note as template | Makes a template from the note you are reading |
| Templates | Opens the Templates group in the sidebar |
| Add task for today | Quick capture dated today |
| New habit | Creates a habit called *New habit* and opens Planner → Habits |
| Sign off for today | The wrap-up sheet (see [Daily rhythm](daily-rhythm.md)) |
| Go to Today | Today's daily note |
| Go to Tasks | Planner → List |
| Go to Notes | The Notes screen, with a **New note** button |
| Go to Habits | Planner → Habits |
| Go to Projects | Planner → Projects |
| Day to the side / Day below | The day glance beside or under what you are looking at |
| Properties to the side / Properties below | The Properties of the note you are writing in, following it |
| Pool to the side / Pool below | The List narrowed to overdue work and tasks with no day |
| Layout: One pane / Side by side / Stacked / Three panes / Four panes | Rearranges the main area into that shape (see [Tabs and the split view](tabs-and-split.md#layouts-one-to-four-panes)) |
| Rail: Show / Rail: Icons only / Rail: Hide | Sets the left sidebar to full, a column of icons, or hidden (see [The sidebar](sidebar.md#full-icons-or-hidden)) |
| Toggle companion | Shows or hides the companion beside the screen, like `Ctrl+Shift+\` |
| Open settings | Settings |
| Settings: Appearance / Writing / Planner / Desk / Account & data / About | Settings, on that group. Typing a setting's name finds its group: *density* finds **Settings: Appearance**, *backup* finds **Settings: Account & data** |
| Activity log | The [activity log](activity-log.md), as a tab |
| Keyboard shortcuts | The [Keyboard shortcuts](keyboard-shortcuts.md) page of this guide |
| Report a bug… | The bug reporter |
| Open help | This guide |
| What's new in this version | The release notes for the version you are running |

Some actions appear only when they apply:

| Action | When |
|---|---|
| Go to *project* | For each project you have pinned |
| New note in *project* | For each active project |
| Layout: *name* | For each layout you have saved, and **Daily log**, which comes with Hollow, while it is on a key. Opens it, replacing the panes and tabs on screen. A layout on a key shows it: **Layout: Daily log (Ctrl+1)** (see [Saved layouts](tabs-and-split.md#saved-layouts)) |
| Duplicate note | While a note is open — copies it |
| File note under *folder* | While a note is open — one per folder, moves the note there |

Your note templates are listed too, marked **Template**: choosing one makes a new note from it.
With nothing typed the palette shows the first twelve; type to find the rest.

Actions can also be reached by their keywords, so `feedback` finds *Report a bug…*, `wrap` finds
*Sign off for today*, and `changelog` finds *What's new in this version*.

## Naming a new project

**New project…** turns the box into a name field: type the name and press Enter. The **New
project…** items in the sidebar and in the Notes tree's **+** menu (**Project…**) open the palette
this way too.
